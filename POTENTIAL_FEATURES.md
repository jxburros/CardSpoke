# Potential Updates for CardSpoke
**Following CardSpoke Objectives V1**

This document lists potential features and improvements that are not currently on the Road Map V1 but align with the CardSpoke Objectives and could enhance the platform.

---

## 🎨 Design & UX Enhancements

### 1. Custom Font Support
- Allow users to select from additional web-safe fonts
- Maintain black and white constraint while offering typographic variety
- Could be implemented as a Theme feature

### 2. Card Layout Options
- Alternative card display modes (compact, expanded, list view)
- Grid view for root cards
- Timeline view for chronological content
- Kanban-style board view for project management

### 3. Focus Mode
- Distraction-free writing interface
- Hide UI elements except current card
- Keyboard-only navigation
- Could include zen/meditation timer

### 4. Typography Presets
- Multiple "reading modes" with different font sizes and line heights
- Preset layouts optimized for different content types (prose, code, lists)
- Dyslexia-friendly font options

## Implementation Priority

These features should be evaluated based on:
1. **Alignment with Core Objectives** - Does it serve the vision?
2. **Modular Implementation** - Can it be a mod/extension?
3. **User Request Frequency** - What do users actually need?
4. **Complexity vs. Value** - Best bang for development buck
5. **Platform Readiness** - Does infrastructure support it?

Many of these features could be implemented as Extensions (Plugins/Mods) rather than core features, maintaining CardSpoke's lightweight philosophy while expanding capabilities.
