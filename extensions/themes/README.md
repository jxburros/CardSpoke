# Notecard on Desk Theme

A beautiful theme that transforms CardSpoke into a realistic notecard-on-desk experience with two distinct aesthetics.

## Theme Modes

### Light Mode - "Afternoon Desk" ☀️
- Warm wooden desk background with subtle wood grain texture
- Cream-colored notecard paper for all cards and UI elements
- Realistic layered shadows that make cards appear lifted off the desk
- Slight rotation on each card for authentic notecard feel (alternating angles)
- Decorative pins/clips at the top of each card
- Paper texture throughout the interface

### Dark Mode - "Midnight Study" 🌙
- Deep midnight blue desk with beautiful starry night effect
- Kraft paper-colored cards with warm amber text
- Warm desk lamp glow effect around cards for comfortable night reading
- Enhanced shadows with ambient lighting
- Stars constellation pattern in the background
- Cozy late-night study aesthetic

## Features

- **Rounded Corners**: 8px border radius on all cards, modals, and UI elements for authentic notecard look
- **Paper Texture**: Subtle paper grain applied consistently across headers, modals, menus, and forms
- **Smooth Animations**: Cards lift and straighten when you hover over them
- **Enhanced Forms**: Input fields with inset shadows for paper-like appearance
- **Beautiful Transitions**: Smooth, natural animations throughout
- **Accessibility**: Maintains high contrast and readability in both modes

## Installation

### Option 1: Via Extensions Hub (Recommended)
1. Open CardSpoke
2. Navigate to Menu → Extensions Hub
3. Search for "Notecard on Desk"
4. Click "Install"
5. Enable the theme from Menu → Appearance Settings

### Option 2: Manual Installation
1. Copy the `notecard-desk.json` file
2. In CardSpoke, go to Menu → Extensions Hub → Install from File
3. Select the JSON file
4. Enable the theme from Menu → Appearance Settings

## Usage

Once installed:
1. Open the menu (three dots in header)
2. Select "Appearance Settings"
3. Choose "Notecard on Desk" from the available themes
4. Toggle between light/dark modes using the theme toggle button in the header
