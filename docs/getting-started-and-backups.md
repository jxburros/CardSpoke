# CardSpoke 1.0 Quick Guide

## Getting Started
- CardSpoke shows a lightweight welcome guide when your library is empty.
- Open it anytime from **Help → Getting Started**.
- Cards can be nested (parents/children) and accept Markdown-style formatting when enabled.
- Tags stay normalized (lowercase strings) and drive both fuzzy search and the Tag Manager.

## Manual Backups
- Go to **Data → Data & Export → Backups**.
- Click **Create Backup Now** to download a timestamped JSON export; no server is contacted.
- Recent backup timestamps are stored locally so you can see when the last download occurred.

## Sharing & Exporting Cards
- From a card page, use **Share** to copy structured JSON or Markdown for the card (optionally including children).
- **Visual Export** renders a printable tree of the card and its descendants; you can print or save to PDF from there.
- **Print** and **Export to PDF** open a printer-friendly view of the card (and optionally its children).
