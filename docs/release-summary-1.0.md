# CardSpoke 1.0 Snapshot

- **Onboarding:** New "Getting Started" guide appears when the dataset is empty and lives under Help.
- **Tags:** Chips now save normalized lowercase strings so Tag Manager counts stay accurate.
- **Search:** Keyboard hint above results and clearer selection outline for ↑/↓ + Enter navigation.
- **Backups:** Manual, timestamped JSON backups with a local history list inside Data → Data & Export.
- **Sharing & Export:** Share modal copies JSON/Markdown; visual export renders a printable tree; print/PDF options use a clean layout.
- **Markdown:** Better list and heading support in Markdown view; improved mobile spacing and print styles.
