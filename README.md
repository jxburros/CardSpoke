# Card Info Base

A lightweight, extensible, multi-platform knowledge base framework that combines hierarchical notes ("cards"), modular extensions ("mods"), and local-first data design.

## 🚀 Version 0.7 - Now with Capacitor!

This version has been converted to use [Capacitor](https://capacitorjs.com/), enabling cross-platform deployment:
- ✅ **Web** - Progressive Web App
- ✅ **Android** - Native Android app
- ✅ **iOS** - Native iOS app (coming soon)
- ✅ **Desktop** - Electron support (coming soon)

## Quick Start

### For Users
Download the latest release for your platform from the [Releases](https://github.com/jxburros/card-based-info-base/releases) page.

### For Developers

```bash
# Clone the repository
git clone https://github.com/jxburros/card-based-info-base.git
cd card-based-info-base

# Install dependencies
npm install

# Start development server
npm run dev

# Build for Android
npm run sync
npm run open:android
```

## Features

- **Hierarchical Cards** - Organize information in nested cards
- **Local-First** - All data stored locally, no server required
- **Extensible** - Mod system for customization
- **Dark/Light Themes** - Multiple theme options
- **Cross-Platform** - Works on web, Android, and iOS
- **Import/Export** - JSON, TXT, and DOCX support
- **Search** - Full-text search across all cards
- **Offline-First** - Works without internet connection
