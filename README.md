# Card Info Base

A lightweight, extensible, single-file knowledge base built with vanilla JavaScript.

## Version 0.7.0 - Foundation Overhaul 🎉

**Current Status:** Schema v4 with full tag/meta/attribute support

Card Info Base is a portable, mod-ready knowledge management system that runs entirely in your browser. No build tools, no dependencies—just open the HTML file and start organizing your information.

## Features

### ✨ Core Features (v0.7.0)
- **Hierarchical Cards**: Organize information in nested, expandable cards
- **Ultra-Light UI**: Clean, modern design with dark/light themes and minimal mode
- **Schema v4**: Full support for tags, metadata, and custom attributes
- **Mod System**: Extensible plugin architecture with lifecycle hooks
- **Mod Taxonomy**: Categorize extensions as Theme, Patch, Plugin, Mod, or Expansion
- **Multi-Instance**: Manage multiple separate datasets
- **Import/Export**: JSON, TXT, and DOCX file support
- **Single File**: Entire app in one portable HTML file
- **Local Storage**: All data stays on your device

### 🎨 Design
- Modern design token system with consistent spacing, colors, and typography
- Dark and light themes
- Regular and minimal display modes
- Fully responsive layout

### 🔧 Developer Features
- Comprehensive developer documentation (see [DEVELOPER.md](DEVELOPER.md))
- JSON Schema definitions for data validation
- AI assistant resources for code help
- Backward compatible with Schema v3 data
- Hook-based mod system for extensibility

## Quick Start

1. Download `Card Info Base Version 0.7.html`
2. Open it in your browser
3. Start creating cards!

## Philosophy

Card Info Base is designed to be:
- **Lightweight**: No bloat, fast load times
- **Portable**: Single file, works offline
- **Extendable**: Mod system for customization  
- **Readable**: Clean, understandable code
- **Educational**: Easy to learn and modify
