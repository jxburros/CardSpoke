## Migration Guide

### For Extension Developers

**If your mod uses old CardSpoke names:**

```javascript
// Old way (still works via backward compatibility)
window.CardSpoke.utils.createCard({ title: 'Test' });
window.CardSpoke_MODS.register('my-mod', { ... });

// New way (recommended)
window.CardSpoke.utils.createCard({ title: 'Test' });
window.CardSpoke.mods.register('my-mod', { ... });
```

**Timeline:**
- **v0.11.3:** Both CardSpoke and CardSpoke names work
- **v1.0+:** CardSpoke names deprecated but still functional
- **v2.0+:** CardSpoke names may be removed

### For Users
**No action required.** All changes are backward compatible.
