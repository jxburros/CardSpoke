## Report Types

### Progress Reports
Track feature implementation against roadmap objectives. Include:
- Feature status tables
- Code evidence with line numbers
- Test coverage analysis
- Roadmap compliance assessment

### Agent Operations
Document AI agent contributions including:
- Campaign planning and execution
- Task breakdowns and dependencies
- Documentation synchronization
- Feature implementation summaries

### Release Notes
Version-specific documentation of:
- New features and capabilities
- Bug fixes and improvements
- Breaking changes (if any)
- Upgrade instructions

### Completion Reports
Document development milestone completions:
- Version completion summaries
- Bug fix resolutions
- Spec compliance verification

### Cleanup Operations
Bulldozer agent reports documenting:
- Files archived or reorganized
- Branch management operations
- Space savings and optimizations
- Safety verification results

## Maintenance

Reports should be generated or updated:
- After each major version release
- When significant roadmap deviations occur
- After agent operations complete
- Quarterly for long-term planning
